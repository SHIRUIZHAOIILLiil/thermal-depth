## Frozen first experiment

Only two arms: frame caption and tokenized empty. No teacher, no zero-loss arm,
no change to any earlier experiment. New output:
`$IRIS_RUNS/outputs/lotus_line_v2/sd21_dual_pair_pad77_v2`.

Padding correction before first submission: all arms/tasks now use exactly77
tokens. Do not reuse any v1 contract, smoke, token cache or checkpoint; this
directory has independent assets/tokens/inventory and a new experiment identity.

Start both arms from the audited original SD2.1-base cache, seed43. Expand the
input convolution from4 to8 channels exactly as Iris (repeat weights then
multiply by0.5, keep bias). Add projection task embeddings with sin/cos of
[1,0] for depth and [0,1] for thermal reconstruction. Keep the latent output
projection. VAE/text frozen, full U-Net/task embedding/direct head trainable.
No continuation from caption-trained, beta=.1 or beta=1 checkpoints.

Direct head reuses models/sd21_tadp.py::DepthHead. Feature taps before upsampling:
up0.resnet1, up1.attention1, up2.attention1, up3.attention2. Only DEPTH samples
enter the direct head; reconstruction samples do not. Output is native256x640
metres through80*sigmoid. The VAE decoder remains available for training loss,
but final validation uses only the direct head.

Total = 1*latent_depth_MSE + 1*thermal_reconstruction_MSE
        + 0.1*VAE_decoded_real_LiDAR_metric_L1 + 1*direct_real_LiDAR_SiLog.

Each term retains its own pixel mean. SiLog lambda=.5, strict real-LiDAR mask
0.001<GT<80. No direct pseudo log-L1, Huber, tail loss or depth balancing.
VAE parameter gradients are disabled, but its decoder passes image-L1 gradients
back into the U-Net. No detach between U-Net features and direct head.

Pseudo source is the existing calibrated_pseudo_depth directory. Preserve its
files unchanged. In memory, reconstruct l100 target: real LiDAR takes priority,
completed depth clipped to[.001,80], log depth normalized by per-frame .02/.98
quantiles of values<80, clipped to[-1,1] and replicated to3channels. This target
transformation is intentionally different from the recent pseudo log-L1 runs.
All required files are audited and hashed; every consumed file is hash-checked.
Nonfinite pseudo files fail before training, rather than filling VAE holes.
Targets and bounds are training-only; neither is available during evaluation.

## Training and fairness

20k updates,4 base images/microbatch, accumulation3 (12 distinct stream positions
per update). Each base image supplies depth and reconstruction tasks. Original
Iris-G t999/sample objective: independently sampled image/target VAE posteriors,
scheduler.add_noise(target,noise,999). Reconstruction always gets empty text.
Fixed max-length77 padding for BOTH arms and BOTH tasks, training and inference.
Tokenizer masks remain metadata only; no explicit padding mask is passed to
CLIP or U-Net cross-attention. Reconstruction tokens/CLIP features are identical
across arms, regardless of depth-caption length. This deliberately differs from
old Iris dynamic padding to remove a reconstruction-conditioning confound.
No horizontal flip (would contradict directional captions), no new augmentation.
Same image order and stochastic draw sequence across arms. Smoke compares actual
VAE latent/noise hashes AND reconstruction CLIP feature hashes per update.

AdamW beta(.9,.999), eps1e-8, weight_decay.01, constant LR3e-5 for U-Net/task
projection and1e-4 for direct head; no warmup; clip global norm1. BF16 U-Net/head,
FP32 VAE/text/loss. BF16 and no-flip mean this is not a bitwise replay of the old
FP16 l100 run. Strict caption evidence is the NEW paired comparison.

Evaluation uses posterior mode and pure Gaussian input noise at t999, fixed by
hash of the thermal input for each image. It needs no GT, pseudo or bounds;
same noise across arms, independent of frame ordering. No multi-sample ensemble.
Metric protocol remains Bridge official .001<GT<80, ssi/none; not final-paper
unified-v1. Select direct-head ssi AbsRel minimum on2k:2k:20k stride4, ties earlier.
Report selected-full and fixed20k separately; full validation14249 frames.
No test evaluation or automatic selection between latent/direct outputs.

## Zeroing the original three losses

Not submitted in this first pair. One extra frame-caption zero-loss arm can
test the old tasks' benefit for the caption model. To test whether old tasks
increase the caption effect requires BOTH frame/empty with old losses zero,
forming a2x2 comparison. Previous TADP runs cannot substitute: task switcher,
