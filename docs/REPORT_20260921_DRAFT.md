## 一、基线 → 换 log 目标

同起点(SD2-base)、同预处理(percentile)、同清单、同步数,**只换训练目标的
归一化空间**。带 caption 臂,推理给本帧 caption,全帧 test。

| 条件 | 训练目标 | AbsRel | RMSE (m) | δ1 |
|---|---|---|---|---|
| 白天 | 视差空间(基线) | 0.07935 | 3.821 | 0.9218 |
| 白天 | **log 深度空间** | **0.07333** | **2.914** | **0.9459** |
| 夜间 | 视差空间(基线) | 0.08179 | 3.515 | 0.9298 |
| 夜间 | **log 深度空间** | **0.07601** | **2.626** | **0.9490** |
| 雨天 | 视差空间(基线) | 0.10584 | 4.600 | 0.8793 |
| 雨天 | **log 深度空间** | **0.09654** | **3.542** | **0.9098** |

⭐ **三个条件、三个指标同时变好。RMSE 降约 0.9 米。**

⭐⭐ 值得单独说一句:此前换过一次深度空间归一化(`r4`),**RMSE 降了但 AbsRel 变差**
(白天 0.0764 → 0.0850)。**log 这次没有付账。** 机制是 `d(log d)/dd = 1/d` ——
固定一步在每个距离上是同样大小的**相对**误差,而视差空间把分辨率花在近处、深度
空间花在远处,所以那两个必然此消彼长。

## 四、架构:模型直接出的是什么,怎么变成米

### 4.1 直接输出

网络吐的是一张 `y ∈ [0,1]` 的图,**没有单位**。它仿射于该帧自己的 **log 深度**:

```
训练时造目标:  log D  →  取该帧的 2% / 98% 分位 lo, hi
               u = 2 (log D − lo) / (hi − lo) − 1        ∈ [−1, 1]
推理时网络给:  y = u / 2 + 0.5                            ∈ [0, 1]
```

⚠️ **那两个分位数是逐帧算的,绝对尺度在"造目标"这一步就被除掉了。** 所以模型
输出没有单位是必然的,不是缺陷。

代码:`lotus/utils/ms2_thermal_dataset.py` 的 `log_truncnorm` 分支。

### 4.2 路线 A:对齐后打分(表一、二、三都走这条)

和所有 affine-invariant 深度方法一样,**逐帧拟合两个参数**再打分:

```
拟合:  a, b = argmin ‖ a·y + b − log D_gt ‖        (只在有激光的像素上)
还原:  D̂ = exp(a·y + b)
```

⚠️ **拟合必须在 log 空间做。** 目标在 log 空间仿射,只有那个空间的拟合能吸收掉
逐帧的 lo/hi。实测代价:

| 打分方式 | AbsRel |
|---|---|
| ⭐ log 空间(正确) | **0.0074** |
| 深度空间 | 0.218 |
| 视差空间 | 0.268 |

代码:`ms2_eval/official_protocol.py` 的 `ssi_log`。

### 4.3 路线 B:预测尺度,不拟合(米制头)

路线 A 用了 test 的真值来拟合那两个参数。**路线 B 改成从热像和 caption 把它们
预测出来,逐像素:**

```
log D̂ = A(热像, caption) ⊙ y + B(热像, caption)
```

`A`、`B` 是两张和图同样大小的图,由一个小网络给出:

```
热像 + y  →  卷积主干  →  与 caption 的 CLIP 嵌入做跨注意力  →  两个头 → A, B
```

**只有 0.39 M 参数,主模型冻结不动。** 监督用真实激光的米制 L1(约 26% 的像素)。

⭐ **初始化上有个设计**:A、B 的逐像素部分零初始化,两个全局标量由训练集拟合,
**所以第 0 步等价于"一个全局仿射"** —— 也就是此前那套两个冻结常数的做法。
任何改善都干净地归因于"逐像素"。

代码:`tools/train_metric_rescale_head.py`,评估 `tools/eval_metric_rescale_head.py`。

### 4.4 两条路线的代价对比(白天)

| | 用了几个 test 真值参数 | AbsRel | RMSE (m) | δ1 |
|---|---|---|---|---|
| 路线 A(逐帧拟合) | 2 | 0.0737 | 2.924 | 0.9453 |
| 路线 B(米制头) | **0** | 0.1136 | 3.714 | 0.8748 |
| 路线 B(+ 逐图中位数缩放) | 1 | 0.0890 | 3.238 | 0.9229 |
| NeWCRF(已发表) | 1 | **0.0716** | **2.430** | **0.9556** |

⚠️ **每少用一个真值参数,数字必然变差** —— 这三行不是三个模型,是同一个模型在
"允许用多少真值"下的三种读法。

⭐ **自己预测尺度的代价是 0.015 AbsRel**(0.0737 → 0.0890,同口径帧集)。

⛔ **和 NeWCRF 同口径(都用 1 个参数)比,我们三项都落后。**

### 4.5 米制头里 caption 的作用

| 条件 | 头里有没有 caption | AbsRel | RMSE (m) | δ1 |
|---|---|---|---|---|
| 白天 | 无 | 0.11584 | 3.768 | 0.8698 |
| 白天 | **有** | **0.11359** | **3.714** | **0.8748** |
| 夜间 | 无 | 0.12420 | 3.733 | 0.8601 |
| 夜间 | **有** | **0.11354** | **3.501** | **0.8795** |
| 雨天 | 无 | 0.14575 | 4.774 | 0.8107 |
| 雨天 | **有** | **0.13746** | **4.585** | **0.8265** |

(零对齐口径,完全不用 test 真值)

⭐ **三个条件三个指标全部更好**,而且夜间那格的幅度比主模型里 caption 的作用大
好几倍。

⚠️ **措辞限制**:喂给头的 `y` 本身是带 caption 推理出来的,所以这里去掉的只是
**头自己**的文本分支。这一格说的是「**在已有几何之上,文本对尺度恢复还有额外
贡献**」,不是「整条管线用不用 caption」。
