## 1. 要回答的问题与现有证据

主问题：相同视觉底座、相同可训练模块和预算下，本帧 caption 是否比固定文本
带来更好的热像深度修正？同时，修正后的模型是否优于不加修正的视觉底座？

目前已知：原两臂固定20000步时，caption 的验证 ssi AbsRel 为0.07093929，
无caption为0.07158152；这是单种子的小幅收益，不等于已证明本帧语义贡献。
8000步的正确/打乱/关闭消融几乎相同，只能说明该checkpoint的推理文本影响很弱，
不能排除训练期帮助，也不能替代20000步机制证据。alpha大小不作为成功标准。

本方案假设：固定已有视觉预测，把新增模块的职责明确限定为修正剩余误差，
比让视觉主干和新文本模块同时自由优化更容易检验文本作用。这是待验证假设，
不是已确认的原模型瓶颈，也不承诺超过NeWCRF。

## 3. 模块职责与最小结构

职责：在视觉预测已经确定的前提下，预测各区域应该往近处或远处修正多少。
不声称文本独立产生精确深度，不把语义名词直接转换成固定物体距离。

冻结底座输出d0。定义b=max(d0,1e-3)，新增分支输出log深度残差r：

`d_final = b * exp(r)`

为避免新分支任意破坏底座，第一版冻结使用：
`r = log(2) * tanh(upsample(u))`，即单像素修正倍率限制在[0.5,2]。
这是工程稳定性约束，不是文献最优值；不根据测试集调整。记录饱和比例，
如果证据显示上限限制学习，保留本轮结果并另行决定新实验，不现场放宽。
训练不把预测截到80m后再计算loss；评估仍使用原官方clamp和mask。

候选实现规格（实现前须用真实DA V2接口和合成张量确认）：

1. 取冻结编码器原四组输出中的第3、4组patch特征，不改变编码器内部计算。
2. 各用独立Linear将768维视觉特征映射到128维；文本token从1024维映射到128维。
3. 将两组视觉特征重采样到原图ceil(H/8)×ceil(W/8)、ceil(H/16)×ceil(W/16)。
   这是人为构造的两种空间分辨率，不冒称DINOv2原始输出本来就是多尺度。
4. 每个尺度做4-head cross-attention：视觉作Q，文本作K/V，显式mask，dropout=0。
   输入分别LayerNorm；视觉投影和attention输出拼接，经Linear融合为128维。
5. 粗尺度双线性上采样到细尺度，与细尺度特征拼接；3×3 Conv(256→128)、GELU、
   1×1 Conv(128→1)输出u。插值align_corners=False。输出裁剪/对齐原始热像尺寸。
6. 最后一层Conv权重与bias置零，其余正常初始化；不再乘额外的零初始化标量alpha。
   初始d_final等于b。第一步主要更新输出层，上游新模块可在随后获得梯度；
   不声称该初始化能保证文本被使用。两臂新增模块逐张量相同初始化。

图像定位细节，文本提供内容相关条件；空间变化残差可改变相对结构，而不是仅
预测会被同表示ssi对齐吸收的全局scale/shift。低分辨率残差不保证恢复薄物体边缘。
第一版不增加第二视觉编码器、不替换DPT、不加伪GT或边界辅助loss。

## 4. 数据、监督与职责的可验证性

训练：官方8段、75688帧，沿用
`ms2_train_official8_thermalcap_v3_1_untrimmed_20260821.jsonl`。
验证：官方3段、14249帧，沿用
`ms2_val_official3_thermalcap_20260821.jsonl`，既有hash前缀c26a5859。
核对完整hash、split与caption来源；两臂用相同热像percentile高位深转换和几何处理。
不随机裁剪/翻转，不插值稀疏GT，不读取伪GT，不读取测试数据参与训练或选点。

有效点：finite(GT)且0.001<GT<80。每帧有效点平均，再在非空帧间平均：

`L = mean_frames mean_valid |r - (log(GT) - log(b))|`

b为冻结预测，目标残差仅在真实激光有效位置定义。此loss与最终预测的masked
log-L1等价，不是额外发明的监督；作用来自任务分解和冻结底座。
不把无激光区域的目标残差填零，不把它们监督为“必须不修正”。
整批无有效GT报错，非有限预测报错；保留近/中/远分段评估，不做分段重加权。

记录真实残差与修正后误差、修正倍率分布、上下限饱和率，以及新模块梯度。
这些是机制/工程诊断，不与深度指标混成一个评分；attention大小也不算贡献证据。

## 5. 固定预算：不因早期小收益改变终点

- seed43；两条臂各20000次新增optimizer更新，batch4×accumulation3，有效batch12。
- 每臂240000帧次，约3.17遍训练集；原底座的训练成本另行披露，不当作从零训练。
- 只训练新增模块；AdamW，lr=5e-5，betas=(0.9,0.999)，weight_decay=0.01；
  poly=(1-step/20000)^0.9，无额外warmup，BF16，梯度范数裁剪上限1.0。
- 主干、深度头、文本编码器都冻结并保持eval，不更新其归一化统计。
- 先两臂各32步真实冒烟，随后正式实验从同一冻结底座和同一新增模块初始状态开始，
  不把冒烟权重带入正式训练。
- 4000/8000/12000/16000/20000步跑完整验证；主结论固定比较20000步，不各自挑点。
  中间点只展示趋势，不设自动科学早停。工程错误/NaN/OOM等立即停，不换单臂batch。
- 每4000步保存完整可训练状态，每1000步更新恢复点；包含optimizer、scheduler、
  RNG、消费图像游标、不可变底座引用/hash，避免反复复制冻结大模型浪费空间。
- 两臂共享确定的数据顺序与初始化；恢复需通过连续训练对照测试。
- 本轮没有自动解冻联合微调、第三训练臂、参数扫描、超过20000步延长或测试投递。
  第二个seed44仅在用户另行批准后用相同两臂、相同预算复现，不视为本次已授权。
- 不预报固定GPU小时数：模块和数据通路实现后由冒烟测量耗时/显存/输出大小，
  再确认完整预算可接受；20000步不是“保证已经收敛”。

## 6. 冻结判断标准

主协议沿用当前DA2的official_protocol：thermal-view LiDAR、原mask/clamp、逐帧均值，
ssi主表，none单独报告。不是切换到另一套最终论文统一协议。全部7项指标和3序列
均报告，不挑天气/序列/指标；近中远分段仅作解释。

定义F=R-frame、C=R-fixed、B0=冻结视觉底座。固定20000步的验证决策：

1. 文本特定收益：AbsRel(C)-AbsRel(F) >= 0.0005（0.05个百分点）；
   RMSE(F)<=1.005×RMSE(C)，a1(F)>=a1(C)-0.001；至少2/3序列AbsRel严格改善。
2. 实际用途：AbsRel(B0)-AbsRel(F) >= 0.0005；
   RMSE(F)<=1.005×RMSE(B0)，a1(F)>=a1(B0)-0.001；至少2/3序列AbsRel严格改善。
3. 两项均通过：值得考虑seed44复现，不称统计显著、最终成功或自动开启测试。
4. 两臂均优于B0但F与C无明确差距：支持新增修正模块有用，不支持本帧caption增益。
5. F优于C但不能改善B0：有相对差异，但当前方案没有达到实际改进目标。
6. 未通过：完成并保留全预算结果，不临时降低门槛、不换指标、不靠继续加步数追分。

0.0005等阈值是预设的工程投入判断标准，不是统计显著性界限，也不是所有论文的
通用贡献门槛。无论是否过门槛都报告实际效应量；单种子结果须标明探索性。
跨seed方向一致性才支持更稳定的贡献，不把相邻视频帧当成大量独立样本。

机制辅助：只对F的20000步checkpoint，在同一验证集比较本帧、固定文本、
seed43无自身匹配的打乱文本；另将残差置零复现B0。记录相同文本/token比例。
它们不是第三条训练臂，也不据此重新选点。若推理扰动不敏感，限制“推理期语义利用”
的表述；若训练对照仍有可靠收益，不自动否定训练期帮助。
