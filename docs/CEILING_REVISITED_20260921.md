# 天花板重测：VAE 从来不是卡住的那个东西（2026-09-21）

## 一句话

两条臂放在同一把尺上量，**都没有贴上各自的 VAE 往返上界** —— 视差臂 1.49×、
log 臂 1.82×。`CEILING_ANALYSIS_20260901.md` 的核心结论（「模型已经精确达到
完美预测目标 latent 的上限」）建立在一次**跨划分**的比较上，换成同划分就不复现。

⛔ **所以「加预算加种子调 caption 都不会动」这句话不能再用来排优先级。**

---

## 一、两条臂，同一把尺

`slurm/ceiling_probe.sbatch`，官方 8 序列训练清单里等距抽 200 帧，**上界与模型跑
同一份子清单**。每条臂各在自己的原生空间对齐，上界那一行跟着换。

| 臂 | 对齐 | | AbsRel | RMSE (m) | δ1 |
|---|---|---|---|---|---|
| **视差** `sd2_cap_pct` s16000 | `ssi_disparity` | 上界 | 0.04049 | 2.009 | 0.98682 |
| | | 模型 | 0.06044 | 2.756 | 0.96936 |
| | | **倍数** | **1.49×** | **1.37×** | |
| **log** `sd2_cap_pct_logtn` s16000 | `ssi_log` | 上界 | 0.02968 | 1.098 | 0.99341 |
| | | 模型 | 0.05407 | 1.906 | 0.98380 |
| | | **倍数** | **1.82×** | **1.74×** | |

作业：7928242（log）、7928465（视差），各 2 分钟。

**两次跑出来的上界两行逐位相同**（探针不含模型，子清单按行等距切、可重放）——
这是这组对照的自洽检查，它过了。

### 对照组也过了

往返相对误差实测 **log 0.0099 / 视差 0.0320**，文档记的是 **0.0096 / 0.0316**。
几乎逐位复现，测量本身可信。

---

## 二、三个读点

**1. 两条臂都没贴上界。** 所以在训练帧上，**VAE 从来不是那个卡住的东西** ——
不是换 log 才移走的，视差臂本来也没贴。

**2. log 把上界抬得比把模型抬得多。** 上界 2.009 → 1.098（1.83 倍），
模型 2.756 → 1.906（1.45 倍）。**换 log 腾出来的空间，U-Net 没吃下多少**，
未用的余量反而更大了。

**3. ⭐ 欠拟合与过拟合同时成立。**

- **相对表示：欠拟合** —— 训练帧上离上界 1.8 倍，没把训练数据榨干
- **相对泛化：已经过头** —— 两个种子的 val 都在 s16000 / s18000 见顶（共 20000 步），
  再训更差（`RESULTS_20260921_LOG_LINE.md`）

**模型没法从训练数据里多拿东西，而不开始背题。** 所以缺口不是预算能填的。

---

## 三、⚠️ 这个测量说了什么，没说什么

探针把**训练目标**过一遍冻结 VAE（编码→解码），再按评估器的规矩对齐打分，
**全程没有模型参与**。它给的是「若 U-Net 把目标 latent 预测得完美，能得几分」。

✅ **能确定**：缺口**不是 VAE 造成的**。

⛔ **不能确定**：缺口是什么造成的。候选至少有四个，探针一个都分辨不了：

| 候选 | 多训能解决吗 |
|---|---|
| 欠训练 | 能 —— 但 val 说已经见顶，所以**排除** |
| U-Net 容量 / 架构 | 不能 |
| condition 信息不足（热像 latent + caption 定不下唯一答案） | 不能 |
| ⚠️ **任务本身的歧义** | **永远不能** |

⛔⛔ **最后一条是硬边界。** 单目热像深度是不定的：同一张图对应无穷多个合法场景。
所以 **1.0× 是达不到的**，而这个测量**测不出现实的下限是 1.2 还是 1.6**。

**「还差 1.8 倍」不等于「还能改善 80%」。** 引用这个数时必须带上这句。

## 四、⚠️ 与旧文档那个 2.996 的差异，未解释

`CEILING_ANALYSIS_20260901.md` 记的视差往返 RMSE 是 **2.996**，我们测出 **2.009**。

最可能的原因是**伪深度版本不同**：旧的用 `pseudo_gt/train_full`，我们用
`pseudo_gt/official_train`（官方 8 序列划分那份，2026-08-22 起在用）。
作业 7927600 那次 2 秒失败，正是因为 `train_full` 已经不在了。

所以那两个数本来也不可比。**未证实，但在解释这个差异之前，别把两份文档的
上界数放同一张表。**

### 旧结论为什么不成立

| | 上界 | 模型 |
|---|---|---|
| 2026-09-01 | 训练帧，视差 | **test**，day |
| 本次 | 训练帧，log / 视差 | **训练帧**，同一批 |

旧那次拿**训练帧的上界**对**test 的成绩**。「test 模型 == train 上界」与
「train 模型 = 1.5 × train 上界」可以同时为真，不矛盾 —— 但前者不能拿来论证
「模型已经榨干这条管线」。

## 五、接缝：一条附带但独立的线索

| | 往返@激光像素 | 往返@伪深度像素 | 比值 |
|---|---|---|---|
| log_truncnorm | 0.0129 | 0.0090 | **1.44** |
| trunc_disparity | 0.0400 | 0.0313 | 1.28 |

整帧 **27.1%** 的像素有真实回波，而覆写处激光与伪深度平均差 **5.7%**。

⭐ **VAE 在「唯一有真监督的那些像素」上重建得最差。** 孤立的真实回波被周围平滑的
伪深度包着，那种尖峰正是自然图像 VAE 不保留的东西。

⚠️ 但注意绝对量级很小（0.0129 对 0.0090），而且这解释不了 1.8 倍的缺口。
**这是覆写方式的问题，不是「VAE 编不了深度图」**，两条路别混。

## 六、对优先级的影响

| 事项 | 本次之前的理由 | 现在 |
|---|---|---|
| PPD 正式跑（24 h） | 「拆掉 VAE」对症 | ⛔ **不对症** —— VAE 不是卡住的东西。仍值得当对比对象，但不再是我们瓶颈的解药 |
| 换 condition / d 线 | 都在天花板下争空间，没意义 | ⭐ **重新活了** —— condition 信息不足是现存候选之一 |
| 加预算 / 加步数 | 没意义 | ⛔ **仍然没意义**，但理由换了：不是撞天花板，是 val 已见顶 |
| caption 线 | 只有 0.3–0.6 点，被天花板压着 | ⭐ **重新活了**，而且它正好打在「condition 信息」这个候选上 |
| 换解码器 / 换底座 | 瓶颈所在 | ⛔ 降级 |
