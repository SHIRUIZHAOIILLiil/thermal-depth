## 三、实验结论(全部已测)

### 阶梯(每级只动一个开关)

| 线 | 相对上一条改了什么 | 结论 |
|---|---|---|
| 第 0 级 `b_gt_full8` | 起点:真实稀疏 LiDAR + 图像空间 SSI-L1,无 teacher | AbsRel/δ1 最好之一 |
| 第 1 级 `L1` | + 补全区伪深度进监督 | ⛔ **十八个格全变差,已结案** |
| `full8` | Iris 表述:latent 损失 + 补全稠密目标(含覆写) | caption 效应最强 |
| `r2` | − 激光覆写 | caption 归零 |
| `r3` | + 米空间图像损失 | ⭐ **十八个格全赢,唯一无代价的改动** |
| `r4` | 归一化换深度空间 | RMSE −0.7~−0.9 m,**代价是 AbsRel** |
| **`r3ow`** | `r3` + 覆写 | ⭐ **caption 效应回来了(9/9),且比 `full8` 全面更好** |

### 两条跨线规律

1. **激光覆写是 caption 效应的必要条件** —— 有覆写的两条(`full8`、`r3ow`)有效应,没覆写的两条(`r2`、`r3`)为零
2. **监督越直接,精度越好、caption 效应越弱** —— `full8`(−0.005)→ `r3ow`(−0.002)→ `r3`(0)落在同一条单调关系上

### ⭐ 度量适配打通了(2026-09-07)

| ⭐ **③ 适配后 + 全局归一化** | **0.0820 / 3.180 / 0.9305** ← 进主表的 |
