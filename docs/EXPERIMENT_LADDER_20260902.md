# 实验阶梯（2026-09-02）

一句话：**主线是一条阶梯,每一级只开一个开关,所以每一级的差值可以归因。**
旁支是另一个训练器上的三条,回答阶梯够不着的问题,**不能和阶梯的级并排比**。

---

## 一、主线：`train_route_suite.py`，`--route b_thermal_unet`

同一个训练器、同一个优化器（AdamW + 余弦调度 + warmup 200）、同样
`seed 42 / 有效 batch 12 / 40000 步 / 官方 8 序列 75,688 帧`。
每一级相对上一级**只多一个开关**。

| 级 | 开关 | 隔离出的问题 | 状态 |
|---|---|---|---|
| **0** | （无） | 起点：只用真实稀疏 LiDAR，图像空间掩码 SSI-L1，无 teacher | ✅ 训练完成 |
| **1** | `PSEUDO_W=1.0` + `PSEUDO_DIR` | **补全区作为监督有没有用**（损失仍在图像空间） | ✅ 训练完成，待评估 |
| **2** | `LATENT_TARGET=1` | **把监督搬到 latent 空间有没有用** | ❌ 未投 |
| **3** | `--lr-schedule constant --warmup-updates 0` | 调度对齐 Iris | ❌ 未投，可选 |

每一级再分 caption 有 / 无两条臂，所以每级两个作业。

|---|---|---|---|
| 1 | 6,308 | 0.0790 | 0.0797 |
| 2 | 12,616 | 0.0760 | 0.0760 |
| **3** | **18,924** | **0.0751** ← 最好 | **0.0742** ← 最好 |
| 4 | 25,232 | 0.0758 | 0.0744 |
| 5 | 31,540 | 0.0760 | 0.0749 |

**两条臂都在约 19,000 步见顶，之后走平并略退。**e3 上三个指标同向：
AbsRel 0.0751→0.0742、RMSE 3.3878→3.3499、δ1 0.9339→0.9354。

⚠️ 但幅度 0.0009 只有种子噪声（约 0.003）的三分之一，而且同一次运行里相邻
epoch 不是独立样本。**现在只能说"方向一致"，不能说"第 0 级上 caption 有效"。**

### 第 0 级的 test（官方 9 序列，全帧 stride 1，逐帧仿射视差空间对齐，best_weights = e3）

2×2：训练时带不带 caption × 推理时喂不喂 caption。原始值，不作差。

| 条件 | 训练 | 推理 | AbsRel | RMSE | δ1 |
|---|---|---|---|---|---|
| day3 (23,311) | 带 caption | 喂 caption | 0.0677 | 3.3315 | 0.9428 |
| day3 | 带 caption | 喂空串 | 0.0681 | 3.3489 | 0.9421 |
| day3 | 无 caption | 喂 caption | 0.0897 | 4.6217 | 0.8919 |
| day3 | 无 caption | 喂空串 | 0.0676 | 3.3516 | 0.9426 |
| night3 (22,916) | 带 caption | 喂 caption | 0.0736 | 3.1858 | 0.9415 |
| night3 | 带 caption | 喂空串 | 0.0741 | 3.2062 | 0.9404 |
| night3 | 无 caption | 喂 caption | 0.0941 | 4.1625 | 0.8922 |
| night3 | 无 caption | 喂空串 | 0.0734 | 3.1953 | 0.9406 |
| rainy3 (25,023) | 带 caption | 喂 caption | 0.0870 | 3.9453 | 0.9105 |
| rainy3 | 带 caption | 喂空串 | 0.0877 | 3.9907 | 0.9084 |
| rainy3 | 无 caption | 喂 caption | 0.1113 | 5.2008 | 0.8470 |
| rainy3 | 无 caption | 喂空串 | 0.0870 | 3.9683 | 0.9091 |

三件事，按效应大小：

1. **给没见过文本的模型喂 caption，它会坏得很厉害**。表里唯一大到无可争议的差别。
   说明文本确实被读进去了，而且是强信号。
2. **cap 权重下，喂 caption 比喂空串好——三条件 × 三指标九个格全部同向。**
   同权重同帧只换文本，种子噪声不适用；是否换种子仍成立未知。
3. **喂空串时，cap 训练反而比 nocap 训练差**，三条件一致。

合起来：训练带 caption 让模型在没有文本时变差，喂上文本正好把这笔补回来，
所以端到端是平的。**「模型在用文本」有证据，「用文本让它更准」在第 0 级没有证据。**

⚠️ **与 `docs/AIRE_RESULTS_20260802.md` 方向相反**。那轮记的是权重效应有益
（b −0.0015）、注入效应有害（b +0.0013），最佳是「cap 训练 + 空 prompt」。
本轮两个符号都翻了。同一条路线，不同的是官方 8/3/9 划分、40000 步、val 选点。

⚠️ 这六个数是**全帧**口径（消融用）。要和已发表基线并排进主表，得另跑
每 10 帧抽 1 的版本（day 2332 / night 2292 / rain 2503）。

## 二、旁支：`lotus/train_iris_ms2_g.py`（Iris 的训练器）

这三条**不在阶梯上**。它们和第 0 级之间隔着六处差异，任何差值都归不了因：

| # | 差异 | 备注 |
|---|---|---|
| 1 | 训练器不同 | |
| 2 | 目标：真实稀疏 → 补全稠密 | |
| 3 | 损失空间：解码图像 → latent | |
| 4 | 重建分支：无 → 有 | 实测占深度项的 1/400 – 1/800，近乎惰性 |
| 5 | 优化器：AdamW → 8-bit Adam | |
| 6 | 调度：余弦 + warmup → 恒定 | |

| 臂 | 问的问题 | 状态 |
|---|---|---|
| `r2_cap` / `r2_nocap` | Iris 的表述搬到热像（逐参数一致，只换三处输入） | ✅ 20,000 步训完，续训至 40,000 排队中 |
| `r4_cap` / `r4_nocap` | ⭐ **归一化 `trunc_disparity` → `truncnorm`** | ✅ 20,000 步训完，续训排队中 |
| `r3_cap` / `r3_nocap` | 在 latent 项之上加**米空间图像损失** | ✅ 40000 步训完，待评估。⚠️ 实测该项占总损失 65%（0.05×SL_I ≈ 0.059 对 latent 0.032），是主目标不是辅助项 |

`r4` 是唯一有明确预期收益的一条：同一张图，深度归一化过 VAE 往返后
RMSE 1.994，视差归一化 2.996，而 NeWCRF 是 2.430
（见 `CEILING_ANALYSIS_20260901.md`）。**归一化这个变量在 route_suite 里够不着**，
只能在这边做。

## 三、口径

- **选点：val 最优点**。val（官方 3 序列）与 test（官方 9 序列）不相交，
  在 val 选、在 test 报是标准做法，不构成泄漏。
- ⚠️ 这个规则**在看 test 之前定死**。已知同一条 caption 效应在两种规则下差 4 倍
  （固定终点 −0.0048~−0.0064，val 最优 −0.00125），所以规则不是装饰。
- 报数时说明是"7 个 checkpoint 中的最优"，让读者自行折算选择偏差。
