# 结果总览与「怎么胜出」（2026-10-10）

所有数字都来自已经跑完、并做过自检的作业。官方子集 = MS2 每 10 帧取 1（day 2331 / night 2292 / rain 2503，
day 少的一帧缺 caption）；全帧 = day 23,311 / night 22,916 / rain 25,023。我们的模型一律 seed 43，各按训练时的
prompt 打分，对齐在 log 空间；NeWCRF / AnyThermal 在深度空间，DA2 在视差空间，PPD 在 log 空间（各在自己的输出空间，
每帧 2 参数）。AbsRel、δ 为百分数，RMSE 为米。

模型简称：
- **ours_img** = `sd2_cap_pct_logtn_img_s43` step16000，带 caption + 米制图像 loss（**新主模型**）
- **ours_cap** = `sd2_cap_pct_logtn_s43` step18000，带 caption、只有 latent loss（原主模型）
- **ours_img_nocap / ours_nocap** = 上面两者不带 caption 的对应臂

### 2.2 能说与不能说
- ✅「在没有激光的区域，我们的预测与补全目标（训练目标）高度一致，NeWCRF 与它差得远。」
- ✅ caption 效应在伪 GT 上更大（latent-only：激光 −0.11/−0.14/−0.13，dense −0.21/−0.19/−0.38，filled −0.24/−0.21/−0.40）
  → 「加 caption 的模型在无激光区与训练目标更一致」。
- ⛔「在伪 GT 上我们比 NeWCRF 更准」：参照在激光上自身误差 8–10%；加米制 loss 的 ours_img 激光上更准却在 filled 比 ours_cap 差
  （排序相反）；AnyThermal 满分。量的是「像不像 AnyThermal」。
- 多帧激光累积已试（`tools/probe_lidar_accumulation.py`）：官方 GT 本身就是累积版，自己再叠位姿漂移 ±1 帧 1–5%、±10 帧 4–11%，
  无法给出无激光区的独立真值。

## 六、怎么胜出：正当的杠杆

差距在 RMSE（0.3–0.5 m）、δ1（0.2–0.4 点）、SqRel；RMSE_log 几乎持平，AbsRel 已经赢。**任何改动的选择都只能用验证集，
测试集只在最后跑一次**——拿测试集挑方法，数字再好也不能报。

| 杠杆 | 预期作用 | 代价 | 公平性 |
|---|---|---|---|
| **A. 测试时集成（多个噪声种子取中位/平均）** | 降方差，RMSE、δ1 常见小幅提升；Marigold / Lotus 都报过集成结果 | 不用训练；推理 ×N | 标准做法，需注明「ensemble N」并报单次结果 |
| **B. 水平翻转测试增强** | 同上，常见小幅提升 | 不用训练；推理 ×2 | 公平起见可对 NeWCRF 同样做 |
| **C. 调米制 loss 权重 λ（现 0.05）** | 米制 loss 直接作用在激光上，加大可能改善 RMSE / δ1 | 每个 λ 一条训练（约 20 h） | 用验证集选 λ |
| D. 更长训练 / 选点 | 不确定 | 训练 | 用验证集 |

建议顺序：**先 A、B**（零训练、几小时可知道有没有用、先在验证集上试），有效再上测试集；C 作为第二步。
⛔ 不可用：换对我们有利的对齐空间、按测试结果挑种子或 checkpoint、在伪 GT 上报「更准」。
