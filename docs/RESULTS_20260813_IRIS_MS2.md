# 完整伪 GT + Iris 训练方式：第一轮完整结果（2026-08-13）

导师 2026-08-11 定的方向：用 AnyThermal 预测与原始 LiDAR 经 scale+shift 对齐生成完整伪 GT，
再按 Iris 的方式训练，**loss 全部基于伪 GT，不再单独使用稀疏 GT**。

评测集统一为 test `2021-08-13-16-08-46`，2,543 帧，官方 BridgeMSD 协议、`ssi_disparity` 对齐、
`condition_latent=mode`。三个主指标：AbsRel ↓ / RMSE ↓ / δ1 ↑。

---

## 1. 做法：复制 Iris 的 trainer，只换数据集

「Iris 的训练方式」有确切所指（论文 §3 + Figure 3 + 他们自己的 `lotus/train_iris_g.py`）：
稠密 GT 深度 → 冻结 VAE 编码成 latent → 加噪 → U-Net 以图像和文本为条件还原 → **loss 算在 latent 空间**。

`train_iris_g.py:1054` 是关键：一个 latent cell 覆盖 8×8 像素，**64 个像素里有一个无效整个 cell 就丢**。
MS2 的 LiDAR 只覆盖约 26.5%，编不出这个目标。**完整伪 GT 正是解开这一步的钥匙**——
导师那句「先造完整伪 GT，再按 Iris 的方式训练」是一个因果链，不是两件事。

**没有去改我们自己的 trainer，而是把他们那份原样复制过来只换数据集**
（`lotus/train_iris_ms2_g.py` + `lotus/utils/ms2_thermal_dataset.py`，改动 21 处全带 `# MS2:` 标记）。
理由是手工对齐的保真度只等于清单的完整度——这一轮就查出四处肉眼扫不到的差别：

| 差别 | 我方原实现 | Iris |
|---|---|---|
| 归一化 | `disparity`（绝对 min/max） | **`trunc_disparity`**（2%/98% 分位 + clip） |
| 损失分支 | 只有深度 | **深度 + 输入图像重建**（`anno_loss + rgb_loss`） |
| 条件 latent | `.mode()` | `.sample()` |
| tokenizer | 补到 77 | `padding=True`（按 batch 内最长） |

**这个决定有实证支持**：同样的完整伪 GT，照原样做 **0.08752**，此前手工逼近的版本
（`b_latent`）**0.09542**，三个指标全好。

⚠️ 其中「条件 latent」一项**单独测过，代价为零**：同一份权重两评，
`abs_rel +0.00000 CI[−0.00000,+0.00000]`、`rmse +0.00001`、`a1 +0.00000`，三个 CI 全跨零。
原因是 SD 的 VAE 训练时 KL 权重极低、后验几乎确定性。那 0.0079 要归给另外三处。

## 2. 训练与选点

| | 带 caption 臂 | 无 caption 臂 |
|---|---|---|
| 步数 | 20,000（Iris 的预算）＝ **12.0 epoch** | 8,000 ＝ 4.8 epoch |
| 墙钟 | 8:00 超时 + 2:10 续跑 | 4:10 一次跑完 |
| 稳态速率 | **1.83 s/优化步** | 同左 |
| val 最佳 | **step 2000（epoch 1.2）** | **step 2000（epoch 1.2）** |

`constant` 调度下前 N 步与更长 run 同轨迹，所以无 caption 臂跑 8,000 步即可，不必跑满。

**两条独立训练的臂最优点落在同一步**，说明该位置由学习率与数据决定，与文本无关。

⚠️ **最佳在 epoch 1.2，不是数据量不够**：同一份 19,949 帧上，b 线（lr 1e-6）到 e5 还在降。
差别是学习率——Iris 的 3e-5 是 b 线的 30 倍，而 `lr × 步数` 两条线同量级
（0.06 vs 0.025），也就是用 12 倍少的步数走了差不多远的距离。

模型选择一律在 **val 序列 11-23-45**（`VAL_STRIDE=4`，1453 帧，与历史训练曲线同口径）上做，
**没有在 test 上挑过 checkpoint**。选点 prompt 与该臂训练时的输入模式一致
（带 caption 的用 `correct`，不带的用 `empty`）。

## 3. 主表

| test 16-08-46 / 2543 帧 | 训练目标 | caption 训练 | 推理 prompt | AbsRel | RMSE | δ1 |
|---|---|---|---|---|---|---|
| b 线 | 稀疏 GT | ✗ | empty | 0.08843 | 3.956 | 0.9071 |
| b + 天空损失（此前最好） | 稀疏 GT + 天空项 | ✗ | empty | **0.08487** | 3.816 | 0.9142 |
| b_latent（手工逼近版） | 完整伪 GT | ✗ | empty | 0.09542 | 3.897 | 0.9034 |
| **iris_ms2 无 caption** | 完整伪 GT | ✗ | empty | 0.08551 | 3.637 | 0.9227 |
| **iris_ms2 有 caption** | 完整伪 GT | ✓ | empty | 0.08752 | 3.761 | 0.9187 |
| **iris_ms2 有 caption** | 完整伪 GT | ✓ | correct | 0.08530 | **3.613** | **0.9231** |

**AbsRel 上没有夺冠**（0.08551 vs 天空损失 0.08487，差 0.7%），**但 RMSE 与 δ1 明显领先**
（3.637 vs 3.816 = 4.7%；δ1 高 0.0085）。三指标二比一，且输的那项差距最小。

定性图（`STYLE=shared`，六帧均匀抽）证实机制：b 线画面上部有大片"判得极近"的暗红，
天空损失把它压平到量程上限（那是在精确执行我们给的常数 1/D_max），
**iris_ms2 既判得远又保留了结构**。

## 4. ⭐ 完整 2×2：与 Iris Table 1 同结构

| | 推理：空 prompt | 推理：真 caption |
|---|---|---|
| **训练不给文本** | **0.08551**（Baseline） | 0.08764（Infer Only）**+0.00213** |
| **训练给文本** | 0.08752（Train Only）**+0.00200** | **0.08530**（Train & Infer）**−0.00021** |

**两个「错配」格子几乎一样差（+0.00200 与 +0.00213，相差 6%），两个「匹配」格子几乎一样好。**

→ **这件事与文本内容无关，与「训练条件和推理条件是否一致」有关。**
训练时给什么，推理时就得给什么；错配一次代价约 +0.002，**两个方向对称**。

### 四组逐帧配对（2543 帧，10000 次 bootstrap）

| 比较 | AbsRel | RMSE | δ1 | 胜率(AbsRel) |
|---|---|---|---|---|
| 有cap：correct − empty | **−0.00221\*** CI[−0.00241,−0.00202] | −0.14807\* | +0.00440\* | **70.2%** |
| 有cap：shuffled − correct | +0.00012\* CI[+0.00001,+0.00023] | −0.00353 | −0.00014 | 48.6% |
| 无cap：correct − empty | +0.00213\* CI[+0.00182,+0.00244] | −0.11226\* | −0.00377\* | 40.9% |
| **Train&Infer − Baseline** | **−0.00021** CI[−0.00045,+0.00003] | −0.02370\* | +0.00033 | 52.5% |

`*` = 95% bootstrap CI 不含零。

**读法：**

1. **`correct − empty` 是七条 caption 线里第一个显著为负的**（前六条 +0.01817\* / +0.0013 /
   +0.00123 / −0.00015(跨零) / +0.00063 / +0.00057）。三指标同向、胜率 66–70%。
2. **但内容只占 5%。** `shuffled`（另一帧的真 caption，同分布、错配对）拿到真 caption
   **95% 的效果**；那 +0.00012 胜率仅 48.6%，另外两个指标跨零且 RMSE 反向 —— 噪声特征。
3. **镜像成立。** 对没训过文本的模型塞文本，AbsRel +0.00213（几乎与 Train Only 等值）。
   四格由同一个机制解释。
4. **净收益：AbsRel 零、δ1 零、RMSE −0.024（0.65%，显著但胜率仅 54.5%）。**
   整套 caption 机制相对完全不用文本，基本是打平。

⚠️ **一处不对称值得记**：`Infer Only` 三指标方向不一致（AbsRel +0.00213 差、δ1 −0.00377 差，
但 **RMSE −0.11226 好**）。给没训过文本的模型塞文本把远端往外推——RMSE 对远端大误差敏感故变好，
AbsRel 偏近端故变差，与 c1「拿远景换近场」同形态。而 `Train & Infer` 三指标同向全好。
→ 文本注入有系统性方向，但只有模型**预期**它时才全面有益。

## 5. 与 Iris 论文逐行对话

Table 1 每个骨干四行，与我们 2×2 一一对应。Lotus-G（AbsRel 百分点，5 数据集均值）：

| | Iris 的 Lotus-G | 我们（MS2 热像） |
|---|---|---|
| Train Only | +0.56 | **+0.20** |
| Infer Only | +0.70 | **+0.21** |
| **Train & Infer** | **−0.72** | **−0.02** |

**两个单边设置同向**（都轻微有害）。**但他们的头条 Train & Infer 是 −0.72 点，我们是 −0.02 点，
差 36 倍。**

而且差在哪是清楚的：他们 Table 5 显示效应**内容驱动**
（空白 6.2 / "An image" 6.1 / 通用模板 6.0–6.1 / 真 caption 5.9）；
我们的内容贡献只占 5%，其余 95% 是条件匹配。

⚠️ `shuffled`（另一帧真 caption）与他们的通用模板不是等价对照，但 b 线上两种都测过、结论同向。

**证据强度**：他们 5 数据集零样本、454–697 张、单次运行、无误差棒、无显著性检验；
我们单序列 2,543 帧逐帧配对 + bootstrap CI。**广度他们强，强度我们强。**

**这是第三次独立检出「无内容信号」**：2026-07-26 b 线 shuffled −0.00006 胜率 49.5%；
2026-08-08 通用模板拿到真 caption 八成效果；本轮 +0.00012 胜率 48.6%。
**尤其这次是在符号翻转（文本终于有净收益）之后仍然成立** —— 收益是真的，来源不是内容。

## 6. 局限

1. **单条 test 序列。** 本项目已有多次 val→test 顺序反转的先例。
2. **`shuffled` 与通用模板不等价**（见上）。
3. **`Train & Infer − Baseline` 的 RMSE 收益（−0.024）是三项里唯一显著的**，胜率 54.5%，
   量级极小，不宜作为「caption 有用」的依据。
4. **checkpoint 按各自训练模式选**，对该臂公平，但 caption 臂的选点用了 `correct`，
   对 `correct` 那一格略微有利。前六条 caption 线用同一协议且全为正，故跨线比较仍公平。
5. **本线的上限是 AnyThermal。** 目标完全来自它之后，「能否超过 AnyThermal」在这条线上失效。
   参考：AnyThermal 在本 test 上 0.0821（`ssi` 对齐，与我方 `ssi_disparity` 不同空间，
   可并排引用但不可换算）。
