# 完整横向对比：三个指标各自的战况（2026-09-25）

## 一句话

**AbsRel 上我们赢下了全部六个对手、全部三个条件。δ1 上只输 NeWCRF。
RMSE 仍然是短板 —— 只赢 DORN、DA2 与 PPD。**

⭐ 而 RMSE 上赢我们的三个（NeWCRF / BTS / AdaBins）都是在 MS2 上从头训的有监督
米制模型；输给我们的三个（DORN 例外）都是大幅微调的基础模型。这个形状值得单列。

## 二、战况：按指标拆

我方最好的一条（log + image loss）对全部六个对手：

| 指标 | 战况 |
|---|---|
| **AbsRel** | ⭐ **十八格全赢**（6 个对手 × 3 条件） |
| **δ1** | 赢 BTS / AdaBins / DORN / DA2 / PPD；**三条件全输 NeWCRF** |
| **RMSE** | 赢 DORN / DA2 / PPD；**三条件全输 NeWCRF、BTS、AdaBins** |

⭐ **RMSE 上赢我们的三个，都是在 MS2 上从头训的有监督米制模型。** 输给我们的
DA2 与 PPD，和我们一样是大幅微调的基础模型。第三次出现的形状（前两次见
`BASELINE_COMPARISON_LEDGER_20260921.md`）：**主干动得越少，远端越稳。**
⚠️ n=3 的观察，是线索不是证据。

---

## 三、⚠️ 引用这些数之前必须一起说的

**1. 基线拿的是 2 参数，比它们发表的口径更强 —— 但只在 RMSE 与 δ1 上。**

NeWCRF day：`median` 0.07052 / 2.700 / 0.95243 → `ssi` 0.07106 / **2.423** / **0.95643**。
RMSE 好了 0.28 米、δ1 好了 0.004，**而 AbsRel 反而差了 0.0005**。

所以「我们给基线更强的口径」这句话对 RMSE/δ1 成立，⛔ **对 AbsRel 不成立** ——
AbsRel 那一栏我们比的是它稍弱的版本。这个方向对我们不利，如实写。

**2. PPD 的预算只有我们的四成。** 4.8 GPU-小时对 12.6，而且 `limit_train_batches: 2000`
让「25 epoch」实际是对数据的约 2.6 遍。

⭐ 但它的 val 在 e014 之后明确变差（0.10582 → 0.11096，是噪声的 4 倍）——
**不是没训够，是训到那里就翻头了。** 这句必须和数字一起出现。

**3. DA2 的 checkpoint 抖动。** 十个点的 val AbsRel 跨度 0.081–0.104。规则可能选到的
那几个点（并列集 `{16000, 18000}`）彼此只差 0.00057，所以**选点的不确定度是 0.0006
量级，不是 0.023**。我方对它的领先远大于此。

**4. 帧数差 5 帧**（day：我方 23,311，基线 23,316）。

## 四、caption：在更强的配方上被吸收了

两条独立训练，配方逐项相同，两臂都按 val 选在 **s16000**（这次没有步数混淆）。

| 条件 | nocap / empty | cap / correct |
|---|---|---|
| day | 0.06834 / 2.722 / 0.9538 | 0.06847 / 2.723 / 0.9523 |
| night | 0.07281 / 2.590 / 0.9522 | 0.07267 / 2.580 / 0.9536 |
| rainy | 0.09213 / 3.436 / 0.9180 | 0.09238 / 3.425 / 0.9192 |

**九格里 nocap 赢 4、cap 赢 5，差值全在 0.0002 量级 —— 分不出来。**

对照**没有** image loss 的那条线：cap 九格同向优于 nocap（day 0.07333 vs 0.07446），
双种子。

⛔ **所以：caption 的两臂效应在加了 image loss 之后消失了。**

⭐ 但注入效应还在：同一份权重，day 给空文本 0.06988、给本帧 caption 0.06847。
准确的说法是 **「模型学会了用文本，但用文本训练并没有让它更好」** —— 两件事可以
同时为真。

**解读**：image loss 提供了 caption 原本提供的东西。两者都是额外监督，后者给的是
真实激光上的米制梯度，一上来前者的边际贡献就没了。

## 五、台账待核 #1：结案

`EXPERIMENT_LADDER_20260902.md` 四点九那张表的基线数，**用的是我方 `ssi` 2 参数
重跑**，不是已发表的 1 参数口径。

证据：`baseline_bench/full_test_day/newcrf_test_day_per_sample.csv` 的 `ssi_*` 列
全帧给出 0.07106 / 2.423 / 0.95643，折算官方子集正是那张表里的 0.0716 / 2.430 /
0.9556；`median_*` 列给出 0.07052 / 2.700 / 0.95243，对不上。

⚠️ 另外记一笔：`runs/qual/` 下同名的 CSV 只有 **600 帧**，而且 `median` 口径下
条件排序是反的（雨天最好）。那是定性子集，**不能当结果用**。
