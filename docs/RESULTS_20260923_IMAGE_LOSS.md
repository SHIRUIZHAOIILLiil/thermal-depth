# 米制图像损失：九格全好，而且它绕开了天花板（2026-09-23）

## 一句话

在 log 目标之上加一项 `lambda_image=0.05`（解码之后在**真实激光**上算米制 L1），
**三条件 × 三指标全部变好**。day RMSE 2.914 → 2.723，AbsRel 0.07333 → 0.06847。

⭐ 这是项目在 **RMSE 与 δ1 上最好的一条线**。

作业：训练 7928645（`sd2_cap_pct_logtn_img_s43`，20000 步，12 小时余），
评估 7931583 / 7931584 / 7931585。

---

## 一、结果

全帧，官方协议，`ssi_log`，`correct` prompt。

| 条件 | 臂 | AbsRel | RMSE (m) | δ1 |
|---|---|---|---|---|
| day | log 线（`lambda_image=0`，s18000） | 0.07333 | 2.914 | 0.94588 |
| day | **+ image loss（s16000）** | **0.06847** | **2.723** | **0.9523** |
| night | log 线 | 0.07601 | 2.626 | 0.94896 |
| night | **+ image loss** | **0.07267** | **2.580** | **0.9536** |
| rainy | log 线 | 0.09654 | 3.542 | 0.90985 |
| rainy | **+ image loss** | **0.09238** | **3.425** | **0.9192** |

### 配方差异

逐项相同：起点 SD2-base、官方 8 序列清单（75,688 帧）、`official_train` 伪深度、
`percentile` 拉伸、`flip=on`、种子 43、20000 步、ckpt 每 1000 步、`log_truncnorm`。

**唯一改动：`--lambda_image` 0 → 0.05。**

⚠️ **但两臂各自按 val 选点，分别落在 s16000 与 s18000。** 同一条 val 规则自动
选出来的，协议上合法，但 `COMPARISON_PROTOCOL_20260826.md` §9 明写过这个坑：
**「两条臂差的不只是那一项，还有训练步数」**。

所以措辞是「配方只改了 image loss；两臂各自按 val 选点」，
⛔ **不能说「唯一的差别是 image loss」。**

## 二、⭐ 为什么它能绕开天花板

`CEILING_REVISITED_20260921.md` 测得：log 目标下，目标过一遍冻结 VAE 的往返上界是
AbsRel 0.02968 / RMSE 1.098（200 训练帧），而模型在 0.05407 / 1.906，差 1.8 倍。

**但那个上界只对「照着目标 latent 抄」的目标成立。** 推导用的前提是
「目标只以过一遍 VAE 的形式被看见」—— 而那个前提来自损失函数：`SL_A` 是 latent 上
的 MSE，网络被要求去够那个 latent。

`image_depth_l1_loss` 把预测 latent **解码**出来，在米制上和真实激光比，
**梯度穿过解码器**。于是网络不必再抄那个压缩码，它可以写一段「解出来更准」的码，
主动补偿 VAE 的往返损耗。

⭐ **RMSE 降了 0.19 米，说明那 1.8 倍的余量确实有一部分是能拿的，不全是任务歧义。**

### 另外两条理由（当初投这一格时写下的）

1. **它是唯一锚在真测量上的项。** latent 那一项的目标是补全图，其中约 73% 的像素
   是 AnyThermal 的伪深度；这一项只读真实激光。
2. **2×2 缺的就是这一格。** `r3` 是视差 + image loss，log 线是 log + 无 image loss，
   两个已有格子各赢一半（r3 的 AbsRel 好、log 线的 RMSE 好得多）。

## 三、损失配比

冒烟与开跑早期实测（第 20 步、前几百步）：

| | 值 |
|---|---|
| `SL_A`（latent 深度） | 0.52 – 0.57 |
| `SL_R`（热像重建） | 0.34 – 0.39 |
| `SL_I`（米制图像 L1，单位是米） | 4.9 – 5.3 |

按 0.05 加权，image 项占 latent 项的约 **32%**（r3 在视差目标下是 65%）。

⚠️ **这个比例是早期的，会漂。** 两项都还远离收敛值，`SL_A` 掉得可能比 `SL_I` 快，
那 image 项的占比会一路上升。**没有测收敛后的比例。**

## 四、caption 还在，但注入效应小了

同一份权重，只换推理时给的文本：

| 条件 | empty | correct | permuted |
|---|---|---|---|
| day | 0.06988 | **0.06847** | 0.06853 |
| night | 0.07414 | **0.07267** | 0.07283 |
| rainy | 0.09446 | **0.09238** | 0.09273 |

三条件都偏 `correct`，方向和 log 线一致。

⚠️ **但注入效应缩小了**：day 的 correct−empty 从 log 线的 0.00223 缩到 0.00141。
**image loss 吃掉了 caption 原本在补的一部分东西。**

内容效应（correct vs permuted）仍然很小：0.00006 – 0.00035，与 log 线同量级。

## 五、⛔ 还缺的那一格

**`sd2_nocap_pct_logtn_img_s43` 正在排队**（训练 7937971 → 评估 7937974/77/80）。

| day AbsRel | cap | nocap |
|---|---|---|
| 无 image loss | 0.07333 | 0.07446 |
| **+ image loss** | **0.06847** | **⛔ 待测** |

**这一格决定汇报第 4 页（两臂 caption 对比）要不要重写：**

- 两臂差仍在 0.001 上下 → caption 的作用独立于 image loss，结论不变
- 差没了 → image loss 提供了 caption 原本在补的东西，第 4 页的立论要重写

⚠️ 注入效应已经缩小了 37%，所以**第二种可能不是空想**。在这一格出来之前，
那十一页不是定稿。
