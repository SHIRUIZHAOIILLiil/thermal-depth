# RGBDT500:RGB-teacher 线打通 + caption 四假设终审(2026-07-21)

本文记录 2026-07-21 一整轮工作。所有数字均为 **BMSD 官方协议原生产出**
(`ssi_disparity` / `--min-depth 0.1` / `--max-depth 20` / `--depth-scale 1000` /
`--min-gt-valid-fraction 0.10`),输出在 `outputs/ms2_official/rgbdt500_*_mind01/`。
配对检验一律逐图配对(n=2817),**均值方向在本项目被配对 CI 推翻过,故不单独引用均值**。

## 0. 一句话

RGB 蒸馏 teacher 让纯热像模型从 **0.3616 → 0.2595**(配对 −0.1021,胜率 90.9%);
caption 在热像上有**真实但边际**的正效应(+0.0025 ~ +0.0088,胜率 50–57%);
针对"为什么 caption 效应这么小"提出的四个假设,**三个否证、一个成立但作用域有限**。

## 2. caption 效应(配对,n=2817)

正 = caption 带来改善;`*` = 95%CI 不含零;括号内为逐图胜率。

| 线 | 基线 | ① 推理注入 | ③ 训了却不给 | ④ 总效果 |
|---|---|---|---|---|
| a 冻结 RGB | 0.2481 | **−0.0005\*** (42.0%) | — | — |
| c 冻结热像 | 0.3825 | **+0.0055\*** (53.4%) | — | — |
| d 端到端 | 0.3616 | +0.0019\* (50%) | +0.0015\* (56%) | **+0.0073\*** (55%) |
| f 端到端 | 0.3985 | −0.0087\* (40%) | **+0.0106\*** (57%) | **+0.0088\*** (53%) |
| RGB-teacher 端到端 | 0.2595 | −0.0047\* (38%) | **−0.0063\*** (43%) | **+0.0025\*** (56%) |

### 读点
1. **零训练即为正**:冻结热像 + caption = +0.0055,无任何训练、无 teacher
   → caption 携带可用深度信息这件事**独立成立**,不依赖 RGB teacher。
2. **符号取决于输入模态**:热像 +0.0055 有益 / RGB −0.0005 有害。
   机制上讲得通——热像丢失颜色纹理语义,caption 补上;RGB 本就有语义,caption 冗余。
3. **三条训练线三种脸**:d 线全为正;f 线"训了扔掉反而更好"(+0.0106,是**正则化**不是信息);
   RGB-teacher 线出现**真依赖代价**(−0.0063,训了不给会比从没用过更差)。
4. ⚠️ **显著 ≠ 有意义**:n=2817 让 0.002 量级也显著,但**九个 caption 效应的胜率全在 38–57%**
   (抛硬币附近)。对比:换 RGB teacher 胜率 **90.9%**。**报 caption 结论必须胜率与 CI 同时给出。**

### 可用于汇报的措辞
> caption 要有用,**必须训练与推理两端同时提供**;只在一端提供反而显著变差
> (推理注入 −0.0047,训练后撤除 −0.0063)。端到端净收益 +0.0025(胜率 56.2%),
> 而同一数据集上改用 RGB 蒸馏 teacher 为 +0.1021(胜率 90.9%),**量级相差约 40 倍**。

## 3. 四个假设的终审

针对"为什么 caption 效应这么小",逐一受控检验:

| 假设 | 判决 |
|---|---|
| ① 缺目标域 thermal–text–depth 联合训练 | **前提有误** + 机制**已否证** |
| ② 缺稠密可靠监督 | **稠密性三重否证** + **精确性两路否证** |
| ③ RGB teacher 让 caption 冗余 | **成立**,但只解释"缩小",不解释"本来就小" |
| ④ caption 缺空间落点 | **两数据集否证**,且更空间化会更差 |

### ① 目标域联合训练
- **前提有误**:`--caption-mode correct` 的臂就是 (thermal, caption, depth) 联合训练
  (caption 编码为 prompt + 热像条件 + GT 深度损失反传)。d/f/RGB-teacher 三线的 caption 臂都是。
  冻结注入只有 a/c,那是**故意设的零训练基线**。
- Iris 确为 RGB-caption-dense-depth(HyperSim + Virtual KITTI,均为合成);
  但其 captioner 是 **LLaVA v1.6 / InternVL3-8B,与我们同源** → "生成器不同"可排除。
- **"迁移到热像不保留文字–几何关联"部分否证**:零训练冻结热像 +0.0055 证明关联**确实传过来了**,只是很弱。
- **我方提出的"颜色词在热像不可落地"机制被自身判决规则否证,方向且相反**:
  `colour_density` 与 caption 收益在 c 线 **rho=+0.067 (p=0.0004) 显著为正**
  (三分位 低 +0.0053 / 高 +0.0064),d 线 rho=+0.062 (p=0.001)。
  更可能的读法:颜色词是"画面中有具体离散物体"的代理变量(`warm_density` 同向为正佐证)。
  工具:`tools/analyze_caption_groundability.py`

### ② 稠密可靠监督
**稠密性——三重否证(此前已完成)**
1. GT 随机抽稀 100%→5%:效应不变(+0.00729 → +0.00728)
2. 真实 MS2 LiDAR 掩码迁移(密度 28.4%):+0.00617 vs 稠密 +0.00729,仅衰减 15%,仍显著
3. 深度分层:增益近/中/远均匀 → 而"GT 盲区掩盖增益"要求增益集中于盲区

**精确性——本轮两路否证**(`tools/analyze_caption_region_and_shift.py`)

*A. 区域分层*(边界 = GT 局部深度梯度前 20%;梯度仅在两侧均有效处计算,避免空洞边界伪装成深度边界)

| 线 | boundary | interior | 判决 |
|---|---|---|---|
| c 线 | +0.0062 | +0.0059 | 相当 |
| d 线 | +0.0072 | **+0.0087** | **interior 反而更大** |

假说要求 boundary ≫ interior,实测相当甚至反向,CI 大幅重叠 → **否证**。

*B. GT 位移校正*(把 GT 平移到度量最优的 −28px 后重新打分)

| 线 | dx=0 | dx=−28 |
|---|---|---|
| c 线 | +0.0055 | +0.0053 |
| d 线 | +0.0073 | +0.0071 |

整体 AbsRel 确有改善(d 线 0.3616→0.3515),但 **caption 效应变化在第四位小数** → **否证**。

**推论:换一个"完美 GT"的数据集,预期 caption 收益仍在 0.005–0.009 量级。据此决定不引入新数据集。**

*口径自检*:该脚本算出的 d 线 dx=0 全图值 = 0.3616 → 0.3543,效应 +0.0073,与官方主表逐位吻合。

### ③ teacher 冗余 —— 成立
同一批 caption、同一份数据、同样热像输入,唯一变量是有无蒸馏 RGB teacher:

| | caption 注入效应 |
|---|---|
| 冻结热像(无 teacher) | **+0.0055 有益** |
| RGB-teacher 模型 | **−0.0047 有害** |

**作用域限定**:d/f 线没有 RGB teacher,caption 也只有 +0.0073/+0.0088。
故冗余解释的是"从 0.0073 缩到 0.0025",**不解释"为什么本来只有 0.0073"**。

### ④ 空间落点 —— 否证,且反向
**MS2(结论 19,已冻结)**:改用 near/middle/far 空间显式 caption 后——

| | AbsRel |
|---|---|
| empty | **0.1238** |
| 空间显式 caption | 0.1308 |
| 故意错的 caption | 0.1315 |

- correct 胜 hard-wrong **52.7%(z≈4.2)** → 模型确实在读、且能分辨对错,通路无故障
- correct 胜 empty **仅 33.1%**,中位差 −0.0055 → **净有害,且比普通散文 caption 伤害更大**(0.0070 vs 0.0013)
- 机制:模型**会"听"、会"照做"、不会"批判地听"**——照单全收 VLM 猜的布局,
  而 VLM 的深度先验**劣于视觉通路自身的估计**。

**RGBDT500(本轮独立复现)**:`spatial_density` 与 caption 收益**显著负相关**
——c 线 rho=−0.050 (p=0.009)、d 线 rho=−0.068 (p=0.0003),三分位 低 +0.0074 → 高 +0.0037。

**且本数据集的 caption 本就是空间分层的**:2817 条 caption 中 foreground/midground/background
各出现约 2900 次(≈每条都有)→ **我们早已在"已落地"状态,效应仍是边际**。

## 4. 统一解释

所有已测数据符合同一条规律:**文本的价值 = 视觉通路有多弱**。

| 视觉通路 | caption 效应 |
|---|---|
| MS2 日间 RGB(最强) | −0.004 |
| RGBDT500 冻结 RGB | −0.0005 |
| RGBDT500 热像 + RGB teacher(被补强) | −0.0047 |
| RGBDT500 冻结热像(被削弱) | **+0.0055** |
| RGBDT500 弱模型 d/f 线 | **+0.0073 / +0.0088** |

且 caption 效应随模型变强单调衰减:d 线 0.3616→+0.0073;RGB-teacher 线 0.2595→+0.0025;
MS2 各线 ~0.12→不显著。
**⚠️ 保留**:强弱两模型的配方亦不同(d 线 vs 实验5 配方),强度与配方混淆,
不是干净的强度操纵;且"强度"与"数据集"本身互相混淆。

MS2 冻结文档当年的预测在此得到印证:
> 语言产生正贡献的必要前提:**文本携带视觉通路无法获取的信息**。
> 唯一可能翻转前提的场景是视觉通路被削弱之时。

热像正是一条被削弱的视觉通路 —— 它翻正了,但幅度边际。

## 5. RGBDT500 深度配准偏移(重要数据集属性)

### 测量
- **RGB↔thermal 对齐**:帧平均相关面峰值 (0,0),train/test 各 200 帧一致,移位增益 0.0000–0.0003;
  乱配对照峰落在随机位置。(`tools/probe_rgbdt500_modality_alignment.py`)
- **RGB↔depth 偏移**:峰值稳定在 **(0, +7)**(两个 split 一致,增益 0.017–0.020,乱配底噪 0.001)
- **度量扫描**:两个**独立模型**均在 **dx=−28** 处见底,`--gt-shift-mode mask` 对照臂全程平坦
  (排除"丢边缘列"伪影),曲线在 −80 处反转(+0.0102)确认是内部极小值:

| | dx=0 | dx=−28 | 惩罚 |
|---|---|---|---|
| 零样本 teacher | 0.2481 | 0.2322 | **−6.7%** |
| 我们训练的学生 | 0.2595 | 0.2535 | **−2.2%** |

**差值的含义**:学生在错位 GT 上训过,**已把一部分容量花在学那个 28px 平移上**
→ 这不只是评估数字偏低,它在实际消耗模型容量。

### 机制(清洗脚本 2026-07-18 已定性记录,本轮量化)
配准残留边界**几乎纯水平**(左中位 52px、右中位 126px、上下 ≈0)= **左右并排(水平基线)相机组**
的指纹。作者用**逐序列一个水平平移**做配准 → **只有一个深度平面完全对齐,其余深度留残余视差**。
这也解释了两个估计量为何不一致(边缘相关性 +7 vs 度量 +28):真实偏移**随深度变化**,
两种加权在同一个函数上得到不同折中值,**7 和 28 都不是"真值"**。

### 定性
**不是数据缺陷,是用途不匹配。** RGBDT500 是**跟踪**数据集,GT 为边界框,
对几像素配准误差不敏感;我们把它挪用于**稠密逐像素深度**,要求严格得多。
清洗脚本对三模态使用**同一裁剪框**,故偏移**非我方引入**。

### 决定:维持现状,不做校正
- 正确修法需**深度相关重投影**,依赖相机标定 —— **RGBDT500 未发布标定文件**(跟踪任务不需要)→ 此路不通。
- 全局平移只是粗糙近似(会把近处校过头、远处校不足)。
- 校正换来评估端约 2%,代价是**所有 RGBDT500 数字作废重跑**(基线、caption 2×2、全表)。
- **配对比较不受影响**(两臂等量抵消);**绝对数字不可作性能声明** —— 沿用既有纪律。

## 6. 方法学教训(本轮踩到的)

1. **小样本第三次误导**:区域分层在 150 张冒烟时显示 boundary(+0.0065)≫ interior(+0.0026),
   全量 2817 张后 d 线**直接反号**(+0.0072 vs +0.0087)。
   前两次为 64 张远景假阳性、val32 四项全升被全量推翻。**冒烟只判"跑不跑得通",不判方向。**
2. **改动"看似只是字符串"的字段前必须小样本验证**:把 runner 生成的 yaml 里 `name: ms2_rgb`
   当标签改掉,导致 `get_dataset` 抛 `NotImplementedError` —— 它是**调度键**不是标签
   (`disp_name` 才是显示用)。已在代码内加注释。
3. **`--gt-shift-x` 这类诊断参数必须配对照臂**:平移会使 |dx| 列失效,若边缘列更难则指标
   会因"删掉难的部分"而改善。加 `--gt-shift-mode mask` 后确认对照臂平坦,结论才成立。
4. **dict 字面量里的重名键会静默覆盖**:给官方评估器加 `reportable` 时与既有键冲突,
   已合并为 `(not smoke) and gt_shift_x == 0`。
5. **RGB 路线的 rescore 需用原始 manifest**:runner 生成的 `selected_manifest.jsonl`
   不含 `thermal_path`,`ms2_eval.io` 会拒绝。
